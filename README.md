# Amazon Order Totals

Academic group machine learning project predicting monthly, state-level Amazon order totals from a crowdsourced dataset of 1.8M+ U.S. Amazon purchase records and customer demographics, built for a UCLA Stats 101C Kaggle competition. Developed with a 4-person team. This repo contains the final tuned random forest model, which produced the team's best-performing submission.

## Data

Raw purchase histories and survey data are not included in this repo due to size. Source: [Open e-commerce 1.0](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/YGLYDY) (Berke et al., MIT Media Lab). Variable definitions are in [docs/data_descriptions.txt](docs/data_descriptions.txt).
